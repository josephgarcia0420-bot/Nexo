Nexo: uso de datos

Versión 0.7.0 · Servicio personal alojado por su propietario.

Acceso a Nexo

El acceso se realiza con Google. El servidor comprueba la identidad mediante Google y usa el identificador estable de la cuenta para separar los datos. Recibe el nombre y correo verificado; no recibe tu contraseña de Google. Solo pueden entrar las cuentas habilitadas por el propietario del servicio. La contraseña antigua de Nexo se verifica únicamente en el navegador para trasladar un perfil local; no se envía al servidor.

Datos financieros y conexión

Las cuentas financieras, saldos iniciales, movimientos, compras, reglas bancarias y cursores de importación se guardan en D1 de Cloudflare. El documento financiero y los permisos de actualización de Gmail se cifran con AES-GCM antes de almacenarlos. El propietario del servicio administra la clave y puede acceder a los datos: no es cifrado de extremo a extremo. Las sesiones revocables de Nexo se conservan temporalmente en el navegador y se verifican en el servidor. El navegador mantiene temporalmente una copia de cambios sin confirmar para recuperarlos si falla el guardado. Nexo requiere conexión para consultar o editar datos. Los datos de la versión local anterior y los archivos de respaldo permanecen hasta que el usuario los borra.

Gmail opcional

Entrar a Nexo no concede lectura del correo. Conectar Gmail es una autorización separada y opcional. Solicita lectura de Gmail para identificar avisos bancarios y convertirlos en movimientos. Ese permiso técnico permite leer el buzón; el servicio está programado para consultar únicamente los remitentes bancarios configurados. No solicita permisos para enviar o eliminar correos, ni acceso para mover dinero bancario.

Datos de avisos

El servicio obtiene la dirección de Gmail y procesa importe, moneda, fecha, concepto y últimos dígitos necesarios para asociar cuenta o tarjeta. Conserva movimientos derivados, identificadores de mensajes y datos mínimos de avisos pendientes. No almacena de forma permanente el cuerpo completo del correo ni adjuntos. Las consultas de conversión a Frankfurter envían solo el par de monedas y la fecha, sin correo, comercio, importe ni cuentas.

Uso limitado

No se utilizan estos datos para anuncios, venta de información ni entrenamiento de modelos. El uso de información recibida de las APIs de Google se limita al registro financiero y debe cumplir la Política de Datos de Usuario de los Servicios API de Google, incluidos los requisitos de Uso Limitado.

Control y eliminación

Puedes cerrar la sesión de Nexo, exportar tu documento financiero y desconectar Gmail desde la app. También puedes retirar permisos desde las conexiones de Google. Desconectar Gmail elimina su conexión, sesiones y avisos del servicio, pero conserva los movimientos ya incorporados a tu cuenta financiera y tus respaldos. Para eliminar toda la cuenta alojada, el propietario debe eliminar sus sesiones, documento y registro de usuario en D1, además de las conexiones de Gmail asociadas; la app aún no incluye un botón para borrar la cuenta completa. Borrar datos del navegador no elimina la cuenta del servidor.
